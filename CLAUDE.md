# CLAUDE.md - permitgu

PermitGU: an unofficial demo of a Guam permit guide modeled on america.gov and PermitSF (sf.gov/permitsf). Built 2026-10-02 at Adam's dad's request (it started as "guamgov"). The guides are still static HTML in `public/`, plus `POST /api/ask`. The residential one-family building-permit tracker is a Next.js app on the same site (`/apply`, `/applications`, `/review`, `/admin`) with Supabase Auth, Storage, and RLS. See `README.md`. It is not a Government of Guam site and it does not take payment.
Live: https://permitgu.vercel.app. guamgov.vercel.app redirects there permanently (`vercel.json`). Vercel project: `permitgu` (id prj_DVqPd4ko6sj0pnQQFcQeP7M3k1KP, scope adamtpangs-projects). Current checkout: `Aether/permit.gu`; repo: `adamtpang/permitgu`, listed in `Aether/fleet.json`. Screenshots: the Browser pane can't capture when this session isn't on screen, so use headless Edge via Playwright (`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`). ## AI answers (`api/ask.mjs`, 2026-10-04)
- How it works: Jev (`~typesafe/jev-latest`, OpenRouter decisions API, about $0.00003 a call) picks a KB topic and a difficulty. Below 0.75 confidence, it loads every topic.
- Models: lookup questions use `google/gemini-2.5-flash` ($0.30/$2.50 per million tokens, about 0.1 cent a question). Reasoning questions use `anthropic/claude-sonnet-5.5` ($2/$10, about 1 to 2 cents), with `reasoning.effort: low`.
- Knowledge base: `kb/*.md` and `api/_kb.mjs` are generated by `python tools/build_kb.py` from the route pages. Re-run it after editing any route.
- Evals: `node evals/run_ask.mjs [baseUrl]` with `KEY_ENV_FILE=<env file>`. The expanded suite has 39 questions, including Tagalog and Korean. Use `MATCH=<regex>` for focused checks. The old 37/37 baseline used weaker grading; the current checks require valid external citations and complete streams. `python evals/route_test.py` checks Jev routing alone. See `QUALITY.md` for regression commands and release gates.
- Key: `OPENROUTER_API_KEY` in Vercel env, which Adam adds himself. Without it the endpoint returns 503 `not_configured`.

america.gov is the standard. Mirror its UI/UX and design: a huge, tight serif headline, lots of white space, deep navy ink `#000c1f`, one big "describe what you need" box with example prompts, pill controls, and rounded cards.
